# PDF Reader plugin

A plugin of MonoAgens: it follows the rules every plugin follows ([spec.md](../../docs/spec.md)
*Plugins*). This file holds only what is specific to PDF Reader.

Fills Workspace's `reader` point for `.pdf`; native (pypdf), no cloud; `dependencies:
[workspace]`. Its library is installed only with it.

**Dependencies** (approved by the owner, installed only with this plugin): `pypdf`.
