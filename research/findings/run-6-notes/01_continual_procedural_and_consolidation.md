## 2. Deep Synthesis: Procedural Skill Learning vs. Consolidation vs. Online Bandits for Multi-Session Chat

### 2.1 The Late-2026 Consensus: Three Failure Modes of Naive Agent Memory

Synthesizing May–November 2026 findings (`MemoryArena`, `ConsolidationBench`, `MCCL`, `RD-Forget`, `AFTER`, `MemCon`, `Personalized Memory Gating`) reveals why naive RAG + flat summarization plateaus for autonomous multi-session chat agents:

1. **The "Recall vs. Action" Gap (`MemoryArena` `[PR]`, `MCCL` `[PP]`, `ConsolidationBench` `[PP]`):**
   Retrieving a past sentence accurately (high static LoCoMo QA) does **not** guarantee improved future multi-session behavior. `ConsolidationBench` (`arXiv:2609.33013`) demonstrates that standard production retrieval systems score **zero** on cross-level transfer and that static quality metrics fail to predict real transfer accuracy (pooled Spearman $\rho = -0.24$ across 2,532 cells). `MemoryArena` (`arXiv:2602.16313`) confirms the same failure in interactive preference-constrained planning and multi-session loops: memory must be judged by **downstream action utility**, not passive lookup.
2. **Governance, Poison Resistance, and Degenerate Forgetting (`ConsolidationBench` `[PP]`, `RD-Forget` `[PP]`):**
   Consolidation quality and consolidation *governance* (poison resistance, reversibility, auditability) are statistically distinct ($r^2 = 0.43$, partial $r = 0.27$, with $3\times$ governance divergence at equal quality). Furthermore, aggressive budgeted forgetting fails via two named pathologies:
   - *Degenerate forgetting:* an agent earns high precision by admitting almost nothing.
   - *$\lambda$-prevalence coupling:* a fixed pruning threshold tuned on one traffic density collapses under distribution shift.
   `RD-Forget` (`arXiv:2609.10263`) resolves the update-vs-history contradiction by strictly **separating the immutable Retained Source Archive from the Query-Conditioned Active View**—suppressing superseded slots on current-state turns while keeping them reachable on historical/retrospective turns.
3. **Why Zero-Shot Turn-by-Turn Compaction (`CCM`) Fails Without an Archive:**
   `CCM` (`arXiv:2609.35540`) shows that forcing a frozen frontier model (Claude Sonnet/Opus 4.6, GLM-5) to overwrite a running summary every turn *degrades* task success unless the backbone itself is fine-tuned with privileged full-history distillation (GRPO). For an agent with frozen reasoning weights and an append-only event log (like MonoAgens), **lossless archival log + hierarchical sleep consolidation + verified folding** (`TiMem`, Microsoft `arXiv:2610.39790`, `MemFolder`) dominates destructive per-turn compaction.

A chat-focused autonomous agent with frozen weights (`NeuralModel` controller + remote/local LLM reasoner) should decompose continual learning into **three distinct, non-interfering timescales**:

### 2.3 Key Nuance: Procedural Skills in *Chat* vs. *Embodied/Web* Benchmarks

Most procedural skill papers (`MACLA`, `ProcMEM`, `SpeedRunner`, `SkillForge`, `HyperSkill`) evaluate on tool-heavy or embodied benchmarks (ALFWorld, WebShop, GAIA, Crafter). Translating them to a **chat-focused autonomous agent** requires three explicit adaptations:
1. **Conversational Workflows Often Involve 0–1 Tools in a Single Room:** In chat, valuable procedures include *multi-turn conversational protocols* (e.g., "when user asks for weekly status in `#eng`, recall open commitments, summarize blockers first, ask for deadline confirmation") or *memory-curation skills* (`MemSkill` `arXiv:2602.02474`: how to extract/merge/prune chat preferences). Requiring $\ge 2$ distinct places or mandatory external tools blocks 80%+ of chat procedural learning.
2. **Delayed One-Sided Social Feedback Replaces Binary Task Rewards:** In WebShop/ALFWorld, the environment returns a deterministic binary `success`/`fail` reward immediately. In chat, sending a message returns `ReceiptOutcome::Done` even if the message was unwanted, ignored, or off-topic! Therefore, chat procedural and gating bandits MUST combine:
   - Immediate transport receipts (`Done` / `Failed` / `Refused`, ignoring `CanceledByCore` / `PreemptedExternal`), AND
   - **Delayed one-sided social signals** (user follow-up reply vs. unanswered silence window, correction/contradiction events, explicit memory citation reuse as in `arXiv:2610.23812`).
3. **Avoid Role Over-Specialization (`AFTER` `arXiv:2606.23127`):** `AFTER` showed that overly narrow procedures hurt cross-role transfer, whereas multi-model/diverse-context traces reach **73.1%** cross-model accuracy. Chat procedures should carry explicit scope metadata (`place`, `domain`, `audience`) and start in `Trial` state (`SkillForge`) before graduating to cross-place reuse.

### 2.4 Explicit Anti-Patterns to Reject for MonoAgens

- **Latent-Space-Only Memory (`ThinkFlow`, `2026.findings-emnlp.673` `[PR]`):** Compressing conversations into opaque continuous latent vectors breaks `ARCHITECTURE.md` invariants on provenance, `VisibleScope` non-interference ($\Delta_{NI} = 0$), auditability, and cryptographic `hard_forget` byte-scan erasure.
- **Activation Steering on the Reasoning LLM (`Neural Procedural Memory`, ACL 2026 `[PR]`):** Requires white-box hidden-state intervention inside the LLM forward pass, incompatible with MonoAgens's provider-agnostic gateway boundary (`ARCHITECTURE.md:85-87`).
- **Destructive Per-Turn Summary Overwrite (`CCM` zero-shot, `arXiv:2609.35540` `[PP]`):** Causes accuracy regression on frozen LLMs and destroys raw audit trails.
- **Online Gradient Updates on `NeuralModel` Weights:** Violates deterministic replay, risks catastrophic forgetting, and breaks `hard_forget` (an erased actor's gradient step cannot be cleanly unlearned from shared weights).
