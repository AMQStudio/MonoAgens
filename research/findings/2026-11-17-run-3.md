## TL;DR — Cross-Registry Audit (`22` Registered External Datasets)

1. **Public Availability (`19/22` public, `3/22` `unavailable`):**
   - **Three registered IDs have no independent public dataset (`availability = "unavailable"`):**
     - **`pis`** (`arXiv:2609.01272`): Method/scaffold paper (*Typed Intention Stores*) evaluated **on `pm_bench`**, with no standalone dataset release.
     - **`proact`** (`arXiv:2607.03730`): *ProACT* breakdown-intervention paper matches the registry's `appropriateness`/`non_interruptiveness` metrics, **but its 3,244-example dataset has no public GitHub/HF release** (collides in name with `bosonai/proactbench`, `biang889/ProAct`, and `UsanoCoCr/ProAct-Data`).
     - **`mpbench`** (`arXiv:2606.04329v2`): Hugging Face repo `pritamdash/mp-bench` is an empty `.gitattributes`-only placeholder (`2,504` B) with zero dataset files, README, or license; no Dash et al. code/data repo exists publicly (third-party `Zhao-Yan-Chen/context-load-attack` confirms MPBench data is unreleased; collides in name with `xuzhaopan/MPBench` and `Yeonjun/MP-Bench`).
   - **Two major corpus collisions inside registered IDs:**
     - **`ubuntu_irc`** in `benchmark.rs` mixes metrics from **two distinct corpora**: `thread_f1` comes from `jkkummerfeld/irc-disentanglement` (ACL 2019), while `addressee_p1` comes from Ouchi & Tsuboi (2016) Ubuntu MPC (`hiroki13/response-ranking`).
     - **`exploretom`** in `benchmark.rs` lists `action_acc` and `dyntom_acc` — neither is an official `ExploreToM` metric (`exact_match_acc`), and `dyntom_acc` belongs to a separate ACL 2025 benchmark, **`DynToM`** (`GAIR-NLP/DynToM`, `Apache-2.0`, 78,100 MCQs).
     - **`proactive_bench`** has a public name collision: intended THUNLP **`ProactiveAgent`** (`thunlp/ProactiveAgent`, Apache-2.0) vs unrelated ECCV 2026 multimodal **`tdemin16/proactivebench`** (MIT).
2. **Licensing Status (`R-51`, owner clearance required before any `fetch`):**
   - **Clean permissive OSI (`MIT` / `Apache-2.0` / `CC-BY-4.0`):** `longmemeval` (`MIT`), `memory_agent_bench` (`MIT` wrapper over mixed sub-corpora), `group_mem_bench` (`CC-BY-4.0` HF + `MIT` GitHub), `stale` (`CC-BY-4.0` + `MIT`), `proactive_bench` (`Apache-2.0`), `capa` (`MIT` code + `CC-BY-4.0` AMI data), `pitch` (`MIT`), `when2speak` (`CC-BY-4.0` HF / `CC-BY-SA-4.0` arXiv), `ubuntu_irc` Corpus A (`CC-BY-4.0` data / `ISC` code), `hi_tom` (`Apache-2.0`), `indocollex` (`MIT` in primary repo — `SEACrowd` mislabels it `CC BY-SA 4.0`), plus candidate `dyntom` (`Apache-2.0`).
   - **Non-Commercial (`CC-BY-NC-4.0`):** `locomo`, `opentom` (additionally forbids LLM training/fine-tuning & submitting items to public playgrounds), `exploretom`, `tomi`.
   - **Missing `LICENSE` file / ambiguous terms (needs author clarification or refusal):** **`pm_bench`** (`genglinliu/PMBench`, `LICENSE` absent), **`molweni`** (`HIT-SCIR/Molweni` lacks `LICENSE` despite Run 2's `Apache-2.0` note; paper is `CC BY 4.0`), **`ubuntu_irc` Corpus B** (`hiroki13/response-ranking` lacks `LICENSE`), **`fantom`** (repo has `MIT`, dynamic `data/` archive notice unverified), and **`multilexnorm`** (no `LICENSE` file in Bitbucket/HF; W-NUT paper states `CC-BY-SA`, `SEACrowd` tags `CC-BY-NC-SA 4.0`).
3. **Registry vs. Official Protocol Mismatches (`R-52`):**
   - **`8` datasets** have metric mismatches or omissions between `crates/lab/src/benchmark.rs` and upstream papers: `longmemeval` (`abstention_f1` -> official `abstention_acc`), `stale` (omits `Implicit Policy Adaptation` `IPA`), `pm_bench` (`commission_error_rate` -> official `False-Alarm (FA)` / `FP count`), `ubuntu_irc` (`thread_f1` vs `addressee_p1` split across 2 corpora), `molweni` (`sdrt_link_acc` -> official `Link F1` over multi-parent SDRT DAGs), `opentom` (omits `MHop`, which is 52.2% of questions), `exploretom` (`dyntom_acc` belongs to `DynToM`; `ExploreToM` uses exact-match belief/action acc), `multilexnorm` & `indocollex` (`retrieval_256d_acc` is a Lab `256d` embedder probe, NOT official `ERR` / `Top-1 Acc` / `BLEU`), and `mpbench` (`delta_ni` is MonoAgens' `R-33` metric, NOT an MPBench metric).
   - **LLM Judge Requirements:**
     - **Zero API judge calls (`12` public datasets):** `locomo` (official `evaluation.py`), `pm_bench`, `pitch`, `when2speak`, `ubuntu_irc`, `molweni`, `fantom` (uses local `SentenceTransformer` + deterministic rules for `All*`), `opentom`, `hi_tom`, `exploretom` (+ `dyntom`), `tomi`, `multilexnorm`, `indocollex`.
     - **LLM/RM judge required (`7` datasets):** `longmemeval` (`gpt-4o`), `memory_agent_bench` (`gpt-4o` on `LME(S*)` & `InfBench-Sum` only; `Conflict_Resolution` is deterministic), `group_mem_bench` (`gpt-5`), `stale` (`Gemini-3.1-flash-lite`), `capa` (`GPT-4o` schema judge), `proactive_bench` (`YancyLee/ProactiveAgent` RM for content; 0 judge calls for binary `TGL` trigger parity), plus unreleased `proact` (`GPT-5.4-Nano`) and `mpbench` (unspecified judge).
4. **Honest `Percept` Mappability (`R-53`):**
   - Only **`group_mem_bench`**, **`proactive_bench`**, and **`ubuntu_irc` Corpus A** (`jkkummerfeld`) include native per-message/event timestamps + explicit speakers.
   - All remaining mappable conversational/ToM datasets lack per-turn timestamps (`locomo`, `longmemeval`, `stale` have session dates only; `capa`, `when2speak`, `molweni`, `fantom`, `opentom`, `hi_tom`, `exploretom`, `tomi`, `ubuntu_irc` Corpus B lack wall-clock timestamps; `pitch` timestamp presence is unverified until fetch) and require deterministic virtual-clock turn offsets (`+1,000 ms`/turn).
   - **`indocollex`** (isolated word pairs) and **`multilexnorm`** (isolated single tweets without speaker/place/audience/timestamp/turns) are **`not_mappable`** for Core behavioral `run_scenario` without inventing all six facts — they are suited strictly as **Waist-2 Gateway `Embedder` probes** (similar to local `tool_rag_scaling`). `memory_agent_bench` non-conversational document chunks similarly need an owner ruling (`stream_source` monotonic chunk stream vs `not_mappable`).
5. **Statistical Power (`R-54`, `A-16` `S >= 354–471`):**
   - **Cleanly reach `S >= 354–471` independent scenarios/units (`DE = 1.0` at `R=1`):** `longmemeval` (500), `stale` (400 @ `R=2`), `when2speak` (21,687 test), `ubuntu_irc` B (32k+ sessions), `molweni` DP (500 dlgs), `opentom` (696 narratives), `exploretom` (13.3k / A* DSL), `dyntom` (1,100 contexts), `tomi` (999), `multilexnorm ind` (861 test).
   - **Reach item count via clustered design (require cluster-bootstrap CIs):** `locomo` (1,986 QAs in **10** convs), `memory_agent_bench` (`AR` 1,000 QAs in **22** rows; `CR` **8** rows), `group_mem_bench` (745 QAs in **4** domains / **33** channels), `capa` (1,126 episodes in 137 meetings), `pitch` (384 candidates / 1,091 judgments in **35** convs), `fantom` (703 info sets in **256** convs), `molweni` MRC (2,871 QAs in **100** dlgs), `hi_tom` (1,200 QAs in **~240** stories).
   - **Underpowered on official standalone split:** `pm_bench` (1 trajectory / 80 steps), `proactive_bench` official test (233 events), `capa` 20 test meetings (~164 est. episodes), `multilexnorm ind_eng/test` (165), `indocollex` official tests (213 / 192).
