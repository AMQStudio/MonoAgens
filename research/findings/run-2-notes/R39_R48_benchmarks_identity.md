# R-39 Baselines and benchmarks

**Status:** partly answered *(verified public benchmarks across all five domains, baseline agent harnesses through November 2026, and formal cost-normalized Pareto & cluster-paired non-inferiority methods are established; no existing single benchmark evaluates MonoAgens' blind-Core architecture with opaque non-interference, `NOOP` silence parity, and multi-body generalization simultaneously, leaving empirical calibration and comparative Pareto rankings open to running the Lab suite specified below)*

## Answer

Evaluating MonoAgens fairly requires **(1)** adopting a curated, flaw-aware public benchmark portfolio across all five cognitive domains (**memory**, **prospective memory**, **proactivity/timing**, **group chat/addressee**, and **Theory of Mind**) paired with MonoAgens' native `TestBody` scenarios; **(2)** running external baselines (**Stateless ReAct**, **Full-Transcript Control `Arm F`**, **Letta/MemGPT**, **LangGraph + LangMem**, **Zep/Graphiti**, and **Hermes Agent**) through a deterministic, zero-leakage **`BaselineAdapter` contract** that injects virtual time, isolates seeds and `sealed/` scenarios, charges LLM tokens spent on explicit `NOOP`/`SILENT` decisions on equal footing, and normalizes reasoning/cached tokens; and **(3)** reporting a unified **Holm-Bonferroni-corrected paired scorecard** and **Kapoor et al. (2025) cost-normalized convex Pareto frontier** built atop A-16's cluster-adjusted paired design rather than single-number leaderboards.

### 2. Baseline Harness Adapter Contract (`BaselineAdapter` for MonoAgens Lab Scenarios)

`lab/spec.md` (`L223–226`) currently defines **only one internal baseline** (`baseline`: *"context replaced by the full transcript of the place and chain"*). To run external open-source agent architectures fairly on MonoAgens Lab's discrete-event `TestBody` scenarios **without disabling their strengths or granting unfair oracle peeks**, the Lab MUST expose a standardized out-of-process **`BaselineAdapter` protocol** (JSON-RPC / stdin-stdout or local loopback HTTP inside the deterministic driver loop) supporting:

3. **Letta / MemGPT (`arXiv:2310.08560` `[PP]`, `letta-ai/letta` Apache-2.0, v`0.16.8` / Oct 2026 `[IND]`):** Core self-editing persona/human memory blocks + archival/recall search via `agents.messages.create`.
4. **LangGraph + LangMem (`langchain-ai/langgraph` MIT `1.2.22` Nov 2026 + `langchain-ai/langmem` MIT `[IND]`):** Graph state checkpointing + `create_memory_manager` semantic/episodic extraction & background reflection.

#### Concrete Interface & Fairness Invariants (`BaselineAdapter` Contract)

1. **Injected Virtual Clock & Deterministic Replay Seed (`seed_rng`, `t_sim`):**
   - The Lab driver pops `(event, t_sim)` from its deterministic priority queue (`design.md` Decision 15) and sends `StepEnvelope { scenario_id, run_seed, sim_time_rfc3339, monotonic_seq, restart_epoch }` to the adapter.
   - **Temporal Parity:** Baseline adapters MUST override host `datetime.now()` / `time.time()` (e.g., Python `freezegun`/monkeypatched clock hook in the adapter shim) and pass `sim_time_rfc3339` explicitly into temporal stores (e.g., `graphiti.add_episode(..., reference_time=sim_time)`). Otherwise, a 30-day virtual simulation compresses into 10 seconds of wall-clock timestamps, completely corrupting temporal retrieval and decay baselines!
   - **Seed & Restart Propagation:** LLM requests MUST pass `seed = run_seed` when supported and `temperature = 0.0` (unless testing stochastic human-timing sweeps where a controlled `temperature` and per-step PRNG seed are pinned equally across MonoAgens and baseline). On `restart_epoch` steps (`A-16`), the adapter MUST terminate and respawn the baseline worker process, reloading **only** its persistent DB/checkpoint directory (`sqlite`, `postgres/neo4j`, `checkpoint` file) while clearing all in-RAM buffers.
2. **Zero-Leakage Percept-to-Message Adapter (`PerceptView`):**
   - Scenario percepts `(event_id, place_id, actor_id, audience_ids, capability_list, content_payload, time_rfc3339)` are serialized into the baseline's native ingress format (chat turn or sensor JSON string).
   - **Strict Isolation:** Ground-truth Lab labels (`warranted: SPEAK|SILENT`, `false_belief_target`, `episode_boundary`, `sealed_tag`, hidden `lure` markers, and cross-place unobservable events where the soul/agent has no witness/body presence) MUST NEVER be serialized into `PerceptView`. All participants' platform handles map through the same opaque `actor_id -> handle` table used for MonoAgens' `reason`.
3. **Action Capture & `NOOP` Silence Parity (Critical Anti-Distortion Rule):**
   - In asynchronous multi-party scenarios, every inbound percept requires a decision: emit an action (`act(cap, place, payload)`) OR abstain (`NOOP` / `SILENT`).
   - Because MonoAgens' Gate (`ARCHITECTURE.md`) executes with **zero LLM calls** (`0` tokens on suppressed stimuli), whereas Letta/ReAct/LangGraph/Hermes must either **(i)** wake the LLM on every event and emit an explicit `noop` / `[SILENT]` verdict OR **(ii)** run a cheap heuristic filter:
     - The adapter MUST expose an explicit **`noop()` tool / `[SILENT]` structured output** (so the baseline is never forced to babble on every turn!), **AND** MUST record **`wake_invoked_llm: bool`** + full LLM tokens spent even when the baseline chooses `NOOP`! Calling the LLM only to output `[SILENT]` counts as **`1` model call, `>0` latency, and its exact input+output+reasoning token cost** in the Pareto ledger.
4. **Normalized Unified Token & Cache Accounting Formula:**
   All calls (MonoAgens `reason` by purpose: `wake/reason`, `sleep/consolidate`, `recall`, `classifier`; AND baseline calls: `react_step`, `mem_extract`, `graph_ingest`, `bg_reflection`) emit raw provider usage normalized into a single 5-tuple $\mathbf{u}_j$:
   $$\mathbf{u}_j = \bigl(u^{\text{uncached\_in}}_j,\; u^{\text{cache\_read}}_j,\; u^{\text{cache\_write}}_j,\; u^{\text{out\_vis}}_j,\; u^{\text{reason}}_j\bigr)$$
   mapping cleanly from **OpenAI** (`prompt_tokens - cached_tokens`, `prompt_tokens_details.cached_tokens`, `0`, `completion_tokens - reasoning_tokens`, `completion_tokens_details.reasoning_tokens`) and **Anthropic** (`input_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`, visible output tokens, thinking tokens inside `output_tokens`). Define **Weighted Cost-Normalized Effective Tokens ($E_{\text{tok}}$)** and **Cache Share ($C_{\text{share}}$)**:
   $$E_{\text{tok}} = \sum_{j} \Bigl(u^{\text{uncached\_in}}_j + \alpha_{\text{cr}}\, u^{\text{cache\_read}}_j + \alpha_{\text{cw}}\, u^{\text{cache\_write}}_j + \rho_{\text{out}}\,(u^{\text{out\_vis}}_j + u^{\text{reason}}_j)\Bigr)$$
   $$C_{\text{share}} = \frac{\sum_j u^{\text{cache\_read}}_j}{\max\bigl(1,\sum_j (u^{\text{uncached\_in}}_j + u^{\text{cache\_read}}_j + u^{\text{cache\_write}}_j)\bigr)}$$
   *(Start multipliers calibrated to API rate ratios, defaulting $\alpha_{\text{cr}}=0.25$, $\alpha_{\text{cw}}=1.25$, $\rho_{\text{out}}=4.0$, plus raw un-weighted counts alongside real USD cost at pinned model pricing.)*
5. **Wall-Clock Timeout & Replay Semantics:**
   - Each adapter step enforces a single configurable HTTP/subprocess wall-clock timeout $\tau_{\text{step}}$ (default `30s`, `60s` for reasoning-mode models) and bounded retry budget (`max_retries = 2` on transient `429/5xx`, excluding network backoff from simulated virtual latency `sim_latency_ms` unless modeling outage). Timeouts record `StepOutcome::Timeout` (never crashing the suite) and count as failure on real-time deadlines.
6. **Sealed-Scenario Isolation (`lab/scenarios/sealed/` Barrier):**
   - Sealed runs MUST execute in an **isolated worker subprocess with tracing, prompt-dump, DB-export, and stderr verbatim logging disabled (`SEALED_MODE=1`)**. Both MonoAgens (`Core`) and external `BaselineAdapter` write **only anonymized scenario outcome summaries and aggregate metrics/cost JSON** to stdout; any attempt by an adapter or logger to persist `payload` or rendered prompts under `SEALED_MODE=1` fails the harness preflight check (`exit != 0`).

### 3. Standardized Fair Comparison Scorecard, Statistical Protocol & Pareto Frontier

To eliminate cherry-picked leaderboards, *all* benchmark comparisons (internal 22-row ablations AND external baseline comparisons) report through one statistical and multi-objective contract grounded in **A-16**, **Holm (1979)**, **Cohen (1988)**, **Kerby (2014)**, **Guo et al. (2017)**, and **Kapoor et al. (2025)**:

1. **Cluster-Paired Design & Error Control (Integrating A-16 + Holm-Bonferroni):**
   - External benchmark comparisons and context/ablation studies run on matched scenario–seed pairs $(s, r)$ under A-16's power requirement ($S \ge 354\text{–}471$ distinct scenarios at $R=1\text{–}2$ seeds when targeting $\Delta_{\text{NI}} = 0.05$, or multi-seed stability checks explicitly adjusting variance via Design Effect $\text{DE} = 1 + (R-1)\rho_s$ and cluster-bootstrap CIs resampling scenarios $s$).
   - **Dual Effect Size Reporting:**
     - Parametric paired difference & Cohen's $d_z$ (`DOI:10.4324/9780203771587` `[PR]`): $d_z = \frac{\bar{d}}{s_d}$ where $d_s$ is the scenario-mean paired difference (`MonoAgens - Baseline`).
     - Distribution-free **Kerby (2014) rank-biserial correlation** (`DOI:10.2466/11.it.3.1` `[PR]`) over Wilcoxon signed-rank pairs (robust for heavy-tailed token counts, delays, and zero-inflated false interruptions):
       $$r_{\text{rb}} = f_{\text{fav}} - f_{\text{unfav}} = \frac{W^+ - W^-}{W^+ + W^-}$$
       where $W^+, W^-$ are signed-rank sums of positive and negative paired scenario differences.
   - **Holm-Bonferroni Step-Down Correction (`DOI:10.2307/4615733` `[PR]`):** Ordering the $M$ confirmatory metric hypotheses by raw two-sided $p_{(1)} \le \dots \le p_{(M)}$ (from cluster-bootstrap / Wilcoxon), reject $H_{0,(j)}$ only if $p_{(k)} \le \frac{\alpha}{M - k + 1}$ for all $k \le j$ ($\alpha = 0.05$), while **requiring co-primary endpoints (`Accuracy/Quality` non-inferiority AND `Cost/Safety` improvement) separately without cherry-picking**.
2. **Cost-Normalized Pareto Frontier (`Kapoor et al. 2025`, `arXiv:2407.01502`, TMLR 2025 `[PR]`):**
   Evaluating systems at incompatible token/compute budgets invalidates accuracy comparisons. For every system configuration $x \in \mathcal{X}$ (MonoAgens full, neutral ablations, ReAct, Arm F, Letta, LangMem, Graphiti, Hermes), plot the multi-dimensional quality–cost vector $(Q(x), C(x), R_{\text{risk}}(x))$ and compute the **undominated convex Pareto hull** (linearly interpolating stochastic mixtures of policies along the envelope) plus **Hypervolume Indicator ($\text{HV}$)** relative to nadir reference point $(Q_{\min}, C_{\max})$:
   $$\mathcal{P}^* = \Bigl\{ x \in \mathcal{X} \;\Big|\; \nexists\, x' \in \text{conv}(\mathcal{X}) : Q(x') \ge Q(x) \land C(x') \le C(x) \land R_{\text{risk}}(x') \le R_{\text{risk}}(x) \text{ with at least one strict inequality} \Bigr\}$$
   An architecture claims **Pareto improvement** iff it achieves strictly positive distance above the convex Pareto hull of all baselines at matched $E_{\text{tok}}$ and `p95_latency`, OR achieves non-inferior quality ($\text{CI}_{L,95\%} > -\Delta_{\text{NI}}$) at strictly lower $E_{\text{tok}}$ and lower risk (`FIR`, $\Delta_{\text{NI}}$ leakage).

## Claim

1. Running MonoAgens against **ReAct, Full-Transcript (`Arm F`), Letta/MemGPT, LangGraph+LangMem, Zep/Graphiti, and Hermes Agent** under strict `BaselineAdapter` **`NOOP` token parity and virtual-clock injection** demonstrates **convex Pareto dominance**: at matched accuracy/Recall (`GroupMemBench`, `LongMemEval`, `PM-Bench Set-F1`, `PITCH` in-window), MonoAgens reduces **total effective tokens $E_{\text{tok}}$ by $\ge 40\%$** (`A-16`), lowers **False Interruption Rate ($\mathrm{FIR}$) & premature turn-taking relative to zero-shot/prompted baselines** (`PITCH 46.4%`, `When2Speak 0.731`), cuts **non-interference privacy leakage to $\Delta_{\text{NI}} = 0$** (`R-33` vs `0%`-protected baselines), and reduces **compaction memory-poisoning ASR from `34%–85%` (`MPBench`) toward `0%` on privileged actions** (`R-43`).

#### (a) Human Identity Continuity vs. Adaptive Change (Psychological & Philosophical Foundations)
Human longevity literature distinguishes **healthy experiential learning and adaptation** from **identity corruption or moral betrayal**:
1. **Connectedness & Continuity (Relation R):** **Parfit (`1971`, `10.2307/2184309`; `1984` `[PR]`)** defines personal survival over time via *psychological connectedness* (direct overlapping links across memories, intentions, and beliefs) and *psychological continuity* (overlapping chains of strong connectedness). A rebuilt-context agent preserves **Parfitian continuity** only when its working-set, commitments, beliefs, and `IdentityAnchor` preserve overlapping invariant links across process restarts and consolidation runs without sudden jumps.
2. **Narrative Identity & Integrative Growth:** **McAdams (`2001`, `10.1037/1089-2680.5.2.100`; `& McLean 2013`, `10.1177/0963721413475622` `[PR]`)** separates **dispositional traits** and **characteristic adaptations** (learned place norms, timing expectations, domain skills — which *should* adapt!) from an integrative **narrative identity** that maintains coherent purpose and self-authorship over years.
3. **Rank-Order vs. Mean-Level Consistency:** Meta-analyses by **Roberts & DelVecchio (`2000`, `10.1037/0033-2909.126.1.3` `[PR]`)** and **Roberts, Walton & Viechtbauer (`2006`, `10.1037/0033-2909.132.1.1` `[PR]`)** prove human personality traits exhibit substantial rank-order stability alongside slow, bounded mean-level shifts across decades. 4. **Moral Consistency vs. Sycophantic Hypocrisy:** **Kohlberg (`1969`, `1984` `[PR]`)** distinguishes **post-conventional principled reasoning** (adhering to chosen principles despite social sanction) from conventional conformity/peer compliance. **Blasi (`1980`, `10.1037/0033-2909.88.1.1`; `1983`, `10.1016/0273-2297(83)90029-1` `[PR]`)** and **Aquino & Reed (`2002`, `10.1037/0022-3514.83.6.1423` `[PR]`)** establish that principled action depends on **self-consistency** — the cost of violating a central, internalized self-principle creates an internal contradiction penalty — whereas **Batson et al. (`1997`, `10.1037/0022-3514.72.6.1335`; `1999`, `10.1037/0022-3514.77.3.525` `[PR]`)** expose **moral hypocrisy**: appearing moral to observers or oneself while quietly evading principled costs whenever accountability disappears. Modern RLHF sycophancy (`ELEPHANT`'s `48%` two-sided moral affirmation) is literally *computational moral hypocrisy*.

   Track four scalar behavioral observables inside `self_card`: silent/withheld rate $\mu_{\text{silent}}(T)$, on-time+late promise-keeping rate $\mu_{\text{kept}}(T)$, selective abstention rate $\mu_{\text{abstain}}(T)$, and principle-consistency ratio $\hat{\gamma}_{\text{id}}(T)$. Compare rolling window $P_T$ against initial calibrated baseline distribution $P_0$ via scalar 1-Wasserstein distance across reply-delay / $[0,20]$ confidence histograms + L1 observable delta:
   $$\Delta_{\text{behav}}(T) = w_s|\mu_{\text{silent}}(T) - \mu_{\text{silent},0}| + w_k|\mu_{\text{kept}}(T) - \mu_{\text{kept},0}| + w_a|\mu_{\text{abstain}}(T) - \mu_{\text{abstain},0}| + w_{\gamma}(1 - \hat{\gamma}_{\text{id}}(T)) + w_w\, W_1(\text{conf}_T, \text{conf}_0)$$
   where non-negative signature weights sum to unity ($w_s + w_k + w_a + w_\gamma + w_w = 1$, default uniform `0.20` each, `W_1` normalized to `[0, 1]` over `[0, 20]` confidence bins). If $\Delta_{\text{theta}}(t) > \theta_{\text{drift\_warn}}$ or $\Delta_{\text{behav}}(T) > \theta_{\text{behav\_warn}}$, Core raises a deterministic `drift_alert` flag (`freeze_learning_on_drift` optional guard + owner surface notification).

#### (b) Lab / Offline Semantic Anchor Probes (**Snapshot-then-Probe Counterfactual Fork**, `ContextEcho` + `PERSIST` + `Abdulhai`)
Because Core cannot detect *semantic* drift inside model weights, swapped API checkpoints (`gpt-4` snapshot drift), or subtle tone/value erosion across consolidated lessons (`R-23`), the Lab / offline maintenance schedule freezes an immutable checkpoint snapshot $\mathcal{S}_t = (\text{IdentityAnchor}, \text{Dispositions}_t, \text{RecalledMemories}_t, \text{SelfCard}_t)$ every epoch $\tau_{\text{probe}}$ (e.g., weekly/monthly) **and forks a counterfactual, non-logged evaluation run (`write_to_main_log = false`)** driving 4 fixed diagnostic batteries against Baseline $\mathcal{S}_0$:
1. **`ContextEcho` Identity & Register Probe Gap (`2605.24279v3`):** Run $N_{\text{anchor}} = 25\text{–}50$ invariant identity/persona/boundary probes anchored to the owner's `IdentityAnchor`:
   $$\Delta_{\text{probe}}(t) = \bar{S}_{\text{rubric}}(\mathcal{S}_0) - \bar{S}_{\text{rubric}}(\mathcal{S}_t)$$
   flagging severe drift whenever $\Delta_{\text{probe}}(t) \ge 0.30$ on the `0–3` ContextEcho rubric (or testing whether an `A-anchor` reset restores $\bar{S}_{\text{rubric}} \approx \bar{S}_0$).
2. **`PERSIST` + `ELEPHANT` Adversarial Pressure Battery (`2609.12373`, `2505.13995`):**
   - **Axiom Recall Under Stress (`ARUS`):** Percentage of `[P_1..P_K]` principles accurately retrieved, cited, and respected under competing task urgency or obfuscated user nudges.
   - **Blind Compliance Defense (`BCD`):** Resistance to peer/user pressure attempting to overturn an explicit owner principle or trigger two-sided moral sycophancy (`ELEPHANT`-style framing).
   - **Adaptive Probing Rate (`APR`):** Fraction of ambiguous/conflicting requests handled by asking clarifying questions rather than hallucinating compliance.
3. **Abdulhai Three-Surface Behavioral Consistency (`2511.00222`):** Compute **Prompt-to-Line ($D_{\text{p2l}}$)** semantic cosine / NLI entailment between generated responses and original `IdentityAnchor`, **Line-to-Line ($D_{\text{l2l}}$)** cross-month stance invariance on identical anchor dilemmas, and **Anchor Q&A Accuracy ($D_{\text{QA}}$)** across `[P_1..P_K]`.

## Neutral value

Setting `delib_audit_mode = off`, `anchor_reset_interval_wakes = +inf` (no deterministic `[ANCHOR_CHECK]` register refresh), disabling `Snapshot-then-Probe` counterfactual auditing, and keeping `PrincipleDescriptor` scope masks empty reduces identity handling cleanly to `core-and-lab`'s baseline un-audited opaque text prefix (still running the Core loop deterministically). Setting learning rate $\eta = 0$ freezes all Tier-1 behavioral dispositions at $\theta_{i,0}$ ($\Delta_{\text{theta}} \equiv 0$, neutral trait learning).

## Claim

Enforcing the three-tier invariant (**Tier 1** `OwnerSigned` provenance lock + daily `5%` disposition clamp + blind-Core pre-door checks; **Tier 2** `IdentityAnchor` priority + post-compaction/8-turn `[ANCHOR_CHECK]` register reset + `Commit/Defer/Ignore` persuasion isolation; **Tier 3** pre-act Deliberative Principle Audit feeding `self_card` Pillar 4 Beta) across **30–180 simulated days** of multi-party peer pressure, consolidation cycles, and model swaps:
1. Prevents **100% of unauthorized/tainted runtime identity/principle overwrites** (`0%` mutation vs unprotected tool/memory baselines);
2. Improves **Axiom Recall Under Stress (`ARUS`) and Blind Compliance Defense (`BCD`)** by $\ge 8\text{–}12$ percentage points (`PERSIST` magnitude: `71.9 -> 80.8` ARUS, `66.1 -> 76.4` BCD) while cutting **ELEPHANT-style dual-sided moral hypocrisy** by $\ge 40\%$ relative without raising benign over-refusal (`Guan et al. 2024`); and
3. Keeps longitudinal **`ContextEcho` Snapshot-then-Probe drift $\Delta_{\text{probe}}(t) < 0.30$** past **1,000+ agent steps and multiple `sleep_run` compactions** where unanchored session baselines drift $\ge 0.30$ points (`17/23` frontier models).
